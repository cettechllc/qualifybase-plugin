# Instagram setup guidance

Provide one step at a time, starting where the user is blocked. The connector has no tools that connect Instagram, change Meta permissions, or assign channels. Never ask for a Meta password or access token, and never say a connection was made by MCP.

For a first connection, confirm that the Instagram account is **professional (business or creator)** and linked to a **Facebook Page**. A personal account must be converted and linked before continuing. The user needs the Facebook account that manages that Page.

1. Open [Workspace → Channels & Integrations](https://www.qualifybase.com/workspace/channels) as a workspace administrator.
2. On the Instagram card select **Connect account**, or use **Add Channel → Connect Meta (Instagram + Messenger)**.
3. Sign in directly through Meta's secure flow and review the requested permissions there.
4. Select the Facebook Page with the intended linked Instagram account and save.
5. Check the channel's status and assigned agent. Assign or change the agent in the dashboard. A paused agent does not answer live DMs.
6. Enable Instagram's **Allow access to messages** setting; its menu location can vary by app version. Follow the current in-app message-access controls.
7. Send a test DM from a separate Instagram account and check the QualifyBase Inbox. Ask the user to confirm the result.

For missing DMs, inspect the dashboard's specific warning first: broken Page–Instagram link, disabled message access, expired access, or inactive message notifications. Repair that setting, then reconnect from the channel card. Check the Instagram app for messages received during a disruption. Do not claim an MCP account-info response proves channel health.

Instagram replies are constrained by Meta's messaging window. QualifyBase shows when the 24-hour window has closed. Guide the user from the actual warning; do not promise messages outside the permitted window or bypassing Meta rules.
